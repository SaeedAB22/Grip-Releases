# Security Policy

## Supported version

Only the latest beta release is supported.

## Verify a download

Download APK files only from this repository's **Releases** section. Every release note will include the APK's SHA-256 checksum. If the checksum differs, do not install the file.

## Report a vulnerability

Do not publish security vulnerabilities, private call information, phone numbers, or exploit details in a public issue.

Until a private security-reporting channel is enabled, open a minimal public issue stating only that you need to report a security concern. Do not include the technical details. The maintainer will provide a private route.
